# HTML Boilerplate Example

This repository contains a basic HTML boilerplate with examples of using CSS media queries.
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
</head>
<body>
    <h1>Heading</h1>
</body>
</html>
```
